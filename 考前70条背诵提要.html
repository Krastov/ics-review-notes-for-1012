考前 70 条背诵提要

使用 CS:APP 常见 Linux x86-64 / AT&T / System V 约定。规则的条件和详细解释请查看完整讲义。

A. 数据表示与整数

  1. 数据由位模式保存，由类型解释；地址说明位置，内存内容说明值。
  2. 一个十六进制位对应四个二进制位，一个字节通常是八位。
  3. 小端低有效字节在低地址；x86-64 是小端。
  4. Linux x86-64 常用 int 4 字节、long 8 字节、指针 8 字节。
  5. w 位无符号范围 0…2^w−1；w 位补码范围 −2^(w−1)…2^(w−1)−1。
  6. 补码最高位权重 −2^(w−1)；同位模式最高位为 1 时，补码值等于无符号值减 2^w。
  7. 补码负数取反加一；全一是 −1；TMin 的同宽正相反数无法表示。
  8. 逻辑运算看零与非零，结果 0/1；按位运算逐位处理；&&、|| 短路。
  9. 左移低位补零；逻辑右移高位补零；算术右移高位补符号位。
  10. 零扩展保无符号值，符号扩展保补码值；截断只保留低位。
  11. 先提升，再确定共同类型，再运算，再转换到赋值目标。
  12. int 与同等级 unsigned int 混合，int 转 unsigned int；更宽有符号类型可能容纳较窄无符号类型。
  13. 无符号算术按模回绕；C 有符号溢出未定义。
  14. 补码加法同号结果反号才溢出；一正一负加法不溢出。
  15. 有符号减法在操作数异号、结果与被减数反号时溢出。
  16. 完整乘积最多 2w 位；同位模式有符号和无符号乘积的低 w 位相同。
  17. C 整数除法向零截断，余数与被除数同号或为零。
  18. 无符号除以 2^k 用逻辑右移；负数向零截断可先加 2^k−1，再算术右移。
  19. 移位数要在提升后的位宽内；机器计数屏蔽不能替 C 非法移位辩护。
  20. x&(x−1) 清最低一；x&(~x+1) 留最低一，注意实际运算类型。

B. 浮点数

  1. V=(−1)^s×M×2^E；存储字段是 s、e、f，e 不等于 E，f 不等于 M。
  2. bias=2^(k−1)−1。
  3. 单精度：1/8/23，bias=127，规格化精度 24 位；双精度：1/11/52，bias=1023，精度 53 位。
  4. 规格化：e 既非全零也非全一，M=1+frac，E=e−bias。
  5. 非规格化：e 全零，M=frac，E=1−bias；f 全零就是带符号零。
  6. e 全一、f 全零是无穷；e 全一、f 非全零是 NaN。
  7. 最小正非规格化数 2^(1−bias−n)；最小正规格化数 2^(1−bias)。
  8. 最大有限数 (2−2^(−n))×2^Emax；同指数区间间距 2^(E−n)。
  9. float 最小正非规格化 2^−149，最小正规格化 2^−126；double 对应 2^−1074、2^−1022。
  10. 范围看指数，精度看有效位数；所有绝对值不超过 2^p 的整数可精确表示。
  11. 默认最近偶数，恰好半数时选最低保留位为零；舍入可能再产生进位。
  12. 浮点加法对阶、加减、规格化、舍入；乘法符号异或、有效数相乘、实际指数相加，再规格化舍入。
  13. 浮点加法和乘法不普遍满足结合律，分配律也不普遍成立。
  14. NaN 不等于自身，有序比较为假；+0 和 −0 数值比较相等。
  15. 32 位 int 转 double 精确，转 float 可能舍入；64 位 long 转 double 可能舍入。
  16. C 浮点转整数向零截断；越界、NaN、无穷没有可依赖的合法整数结果。

C. 汇编与控制流

  1. AT&T 源在前、目的在后；$ 是立即数，% 是寄存器。
  2. b/w/l/q 分别是 8/16/32/64 位；movl 的 l 不代表 Linux C long 的宽度。
  3. 写 32 位寄存器清对应 64 位寄存器高半部；写 8/16 位仅改相应部分。
  4. 内存地址 D+base+index×scale，scale 只取 1/2/4/8，偏移按字节计。
  5. mov 读写数据，movs 符号扩展，movz 零扩展；lea 算地址数值而不读内存。
  6. 二元指令更新第二操作数，sub S,D 是 D−S。
  7. sal=shl；shr 补零；sar 补符号；可变移位计数常在 cl。
  8. 单操作数 mul/imul 的完整乘积在 rdx:rax；rdx 高、rax 低。
  9. div/idiv 的被除数是 rdx:rax；商 rax、余数 rdx；有符号 64 位除法常先 cqto。
  10. ZF 看零，SF 看最高位，CF 看无符号进借位，OF 看有符号溢出。
  11. cmp S,D 用 D−S，test S,D 用 D&S，二者不保存运算结果。
  12. mov、lea、not 不改条件码；inc、dec 不改 CF；跳转读最近有效的相关条件码。
  13. 有符号小于 jl：SF≠OF；小于等于 jle：ZF=1 或 SF≠OF。
  14. 有符号大于 jg：ZF=0 且 SF=OF；大于等于 jge：SF=OF。
  15. 无符号小于 jb：CF=1；小于等于 jbe：CF=1 或 ZF=1。
  16. 无符号大于 ja：CF=0 且 ZF=0；大于等于 jae：CF=0。
  17. 相等 je 看 ZF=1，不等 jne 看 ZF=0。
  18. setcc 只写一个字节；完整布尔值常再 movzbl。
  19. cmov 条件写目的寄存器，但不能普遍替代条件分支的安全求值。
  20. 循环找初始化、更新、条件和回跳；switch 表项可能是地址或相对偏移。

D. 过程调用与内存布局

  1. 栈向低地址增长，rsp 指向栈顶；push 通常减 8，pop 通常加 8。
  2. call 压下一条指令地址并转到函数；ret 弹返回地址并跳回。
  3. 函数预留空间减 rsp，回收空间加 rsp；ret 前 rsp 要指向返回地址。
  4. System V 整数/指针参数：rdi、rsi、rdx、rcx、r8、r9；普通整数返回 rax。
  5. 简单第七个整数栈参数在入口常是 8(%rsp)，入口 0(%rsp) 是返回地址。
  6. 被调用者保存：rbx、rbp、r12～r15；调用者保存的值若还要用，由调用者先存。
  7. call 前普通 rsp 对齐 16；入口 rsp+8 对齐 16；rbp 帧指针可省略。
  8. call 改变 rsp，已有局部对象的绝对地址不自动改变；其相对偏移会改变。
  9. 一维数组地址 A+i×L；二维连续数组地址 A+(i×C+j)×L。
  10. 指针数组访问先读行指针；连续二维数组直接按固定行宽算位置。
  11. 指针加一走一个目标对象；汇编地址偏移始终按字节。
  12. 结构体逐成员对齐、最后整体对齐；总大小包含填充。
  13. 联合体成员重叠，整体空间按最大需求与对齐确定。
  14. XMM 常存浮点参数与结果；ss 单精度、sd 双精度；浮点比较另处理无序 NaN。
